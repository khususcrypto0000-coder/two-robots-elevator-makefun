One awkward line of small talk from one robot to another, stuck together in an elevator: its proximity sensor has already decided they are friends, and it is quietly begging the other robot not to correct the sensor.

## Run it

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt`.
